## 📋 Description
A data analysis project exploring crime patterns across London boroughs. Uses the London Crime Dataset (2008-2016) to identify trends, high-risk areas, and correlations with socio-economic factors through statistical analysis and interactive visualizations.


## 🎯 Objectives

- Analyze crime trends across different London boroughs
- Identify high-risk areas and seasonal patterns
- Explore correlations between crime rates and socio-economic indicators
- Build interactive visualizations for better insights


## 📊 Dataset

- **Source:** London Crime Dataset (2008–2016)
- **Records:** ~13.5 million+
- **Features:** Borough, Crime Type, Date, Location, etc.


## 🛠️ Tech Stack

- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Plotly
- **Environment:** Jupyter Notebook
